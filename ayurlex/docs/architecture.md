## System Architecture Diagram

```mermaid
graph TD
    User((USER)) -->|Next.js Frontend| API[FastAPI API]
    API -->|Request Validation| ORCH[AI Orchestrator]
    ORCH -->|Session Context| MEM[Memory Module]
    ORCH --> QC[Query Classification]
    ORCH --> TE[Terminology Engine]
    ORCH --> JE[Jurisdiction Engine]
    ORCH --> RAG[Hybrid RAG / ChromaDB]
    RAG <--> KB[(Knowledge Base)]
    ORCH --> IP[IP Intelligence]
    ORCH --> REG[Regulatory Intelligence]
    ORCH --> LLM[LLM Synthesis / Provider]
    LLM --> ORCH
    ORCH -->|Citation & Confidence| Response[Final Structured Response]
    Response --> API
    API --> User
```
